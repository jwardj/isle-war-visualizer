# Drop your DLV agents here

Put any `*.dlv` file in this folder and it shows up automatically on the start
screen as a pickable controller — no code changes needed.

1. Save your (or a friend's) agent as `<name>.dlv` here, e.g. `team7.dlv`.
2. Launch the game (double-click `run.bat`).
3. Click a player slot until it shows your filename, then **Start Game**.

The full rule contract — what facts your agent is given each phase and what
atoms it should answer with — is in **`../bots/README.md`**. The shipped bots in
`../bots/` are good working examples.

Files starting with `_` are ignored (handy for notes or work-in-progress).
